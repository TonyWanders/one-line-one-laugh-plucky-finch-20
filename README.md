One funny line, at most 200 characters, for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on [make.fun](https://make.fun).

`main.py` (Python, standard library only) writes the line to the output target: `argv[1]`, else `$OUTPUT_PATH`, else `/output/entry.txt`.

```
python3 main.py /output/entry.txt
```
